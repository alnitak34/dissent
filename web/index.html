The whole case in plain English

Alnitak locked 3 test MON behind a 68.57% claim that had to stay above 36.29%. A challenger revealed the permitted OVERBET evidence tier. The registered adapter recalculated 17.70% onchain, so Dissent awarded 3.10 test MON to the challenger.

This proves the settlement under the registered rule. It does not declare that the evidence describes universal real-world truth.

Why did 68.57% become 17.70%?

The first number used Alnitak's declared opponent model. The challenge supplied a stricter permitted tier for an overbet. The adapter then enumerated every possible remaining two-card opponent hand and applied the same public rule. There is no random Monte Carlo draw and no LLM deciding who is right.

Why this exists

A result is not evidence that the decision was sound.

Autonomous agents increasingly produce numbers that trigger actions: risk scores, prices, probabilities, expected returns and safety limits. Logs can explain what happened, but they do not create an economic consequence when the number is wrong.

Dissent is the neutral mechanism between a claim and its consequence. It handles escrow, sealed challenges and settlement. Domain-specific recomputers define what the number means.

Trust boundary

The protocol guarantees the mechanism.
The adapter defines the meaning.

Dissent is not an oracle of truth. Production users should require immutable, audited and publicly verified recomputers. This boundary is explicit in the protocol instead of hidden behind an AI evaluator.
