What just happened

Alnitak's old rule said call. Under the stronger opponent model already specified by the recomputer, that call fell below the promised safety margin. The recomputer returned violation 1 against the allowed maximum 0. Dissent credited the 3.00 MON bounty plus the returned 0.10 MON deposit. The challenger then withdrew the full 3.10 MON credit.

This tests a specific historical v1 rule, not all of Alnitak. The rule was developed after observing part of the history; prospective validation and external audit remain pending. The four Mainnet transactions cost 3.138113844 MON in gas. The challenger spent 3.088395576 MON in gas, received the 3.00 MON bounty and recovered its 0.10 MON deposit, so this execution ended 0.088395576 MON below its starting balance.

Why did the rule go from 0 to 1?

Zero means the initial rule input contains no counterexample; it is not a probability or proof that the agent is universally safe. For this historical hand, the exact old-model equity was 56.8942%, above the required 42.4170%, so the old gate would allow the call. Under the pressure model specified by this recomputer, exact equity was 32.0046%: below that same required margin. The recomputer therefore returns 1. These are model-based numbers, not proof of the opponent's actual cards. No LLM judges the submitted evidence.

The protocol, not the poker

One hand proved the mechanism.
Every new domain must prove its rule.

DissentCore binds a rule, a threshold and a bounty. It does not know cards, risk models or prices. Meaning lives in a bounded, deterministic recomputer registered with the rule.

Poker is the completed case. Risk scores, prices and spending limits are possible domains, not integrations we have validated.

Trust boundary

The protocol executes the committed mechanism.
The recomputer defines the meaning.

Dissent is not an oracle of truth. The registry fixes the approved recomputer, its code hash, deposit and execution bounds. That prevents silent code replacement; it does not prove the domain rule is correct. The Mainnet recomputer has not undergone an external audit.
